Cleo · CleoPER

Política de privacidad

Última actualización: 19 de noviembre de 2026

Cleo (registrada en Google como CleoPER) es un asistente personal que desarrollo y uso yo mismo en mi propia computadora. No es un servicio público: no tiene registro abierto, no tiene otros usuarios y no se vende.

Qué datos de Google lee

Con mi autorización, Cleo usa permisos de solo lectura:

  • Google Calendar (calendar.readonly): mis próximos eventos.
  • Google Classroom (classroom.courses.readonly, classroom.coursework.me.readonly, classroom.announcements.readonly): mis cursos, tareas, fechas de entrega y avisos.

Cleo no crea, modifica, borra ni envía nada en esas cuentas.

Para qué se usan

Solo para recordarme pendientes y entregas, y para armar mis resúmenes del día dentro de la misma app.

Dónde se guardan

Los datos se guardan en una base de datos local en mi computadora. No se suben a servidores propios, no se comparten con terceros, no se venden y no se usan para publicidad. Los tokens de acceso se guardan en archivos locales que solo puede leer mi usuario del sistema.

Uso limitado

El uso y la transferencia de información recibida de las API de Google se ajustan a la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de Uso limitado.

Cómo revocar el acceso

El acceso se puede retirar en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, Cleo deja de leer esos datos; los que ya estén guardados en local se pueden borrar a petición.
